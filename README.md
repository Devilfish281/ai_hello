# AI Hello

A Python project demonstrating AI-powered hello world functionality.

## Project Structure

```
.
├── src/
│   └── ai_hello/
│       ├── __init__.py
│       ├── main.py
│       └── hello_world/
│           ├── __init__.py
│           └── hello_world.py
├── tests/
│   └── __init__.py
├── pyproject.toml
└── README.md
```

## Installation

1. Clone or download the project
2. Install dependencies using Poetry:

```bash
poetry install
```

## Usage

Run the main application:

```bash
python -m ai_hello.main
```

## Testing

Run tests using pytest:

```bash
pytest
```

## Requirements

- Python 3.8 or higher
